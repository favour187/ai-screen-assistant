API Reference

shared protocol 1.0.0
All clients (Windows / Android / this dashboard) use the same Node backend. No SDK key ever leaves the server. Docs also at / (JSON).

GET /health

public
http
curl https://your-backend/health
→ { status, checks:{openrouter}, version, uptime }
Also /health/live & /health/ready for probes.

GET /api/models

http
curl https://your-backend/api/models
→ { models: [{id,name}] } // cached 60s
Used for model picker. Filters via OPENROUTER_ALLOWED_MODELS.

POST /api/vision/analyze

JSON | multipart
json
{ 
  "prompt": "Describe this screen",
  "imageBase64": "data:image/jpeg;base64,…",
  "model": "anthropic/claude-3.5-sonnet",
  "stream": true, "autoContinue": true
}
curl
curl -X POST https://your-backend/api/vision/analyze?stream=true \
  -H "Content-Type: application/json" \
  -d '{"prompt":"...","imageBase64":"data:image/jpeg;base64,..."}'
SSE when ?stream=true or {stream:true} — events: meta delta done continuation error. Non-stream returns { answer, metadata, continuation }. Limits: 15 MB JSON, 10 MB image, 16k tokens max.

POST /api/chat

json
{
  "messages": [{ "role":"user", "content":"..." }],
  "model":"openai/gpt-4o", "stream": true,
  "maxTokens": 4096, "temperature": 0.7
}
Stream via /api/chat/stream (SSE). Continue truncated via /api/chat/continue.

Security & Limits

  • OPENROUTER_API_KEY is server-only — never exposed to clients.
  • Helmet, CORS allowlist, rate limits: 80 req/60s baseline, 30 vision, 20 streams.
  • Request ID (X-Request-Id), pino logs, 180s timeout for large streaming.
  • See shared/src/protocol.ts for the single source of truth.
